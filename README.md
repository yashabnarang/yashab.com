# yashab.com

Personal portfolio site for [Yashab Narang](https://yashab.com).

## Stack

- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- TypeScript

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Note:** Next.js 16 requires Node.js 20.9+. Vercel uses a compatible runtime automatically. For local dev, upgrade Node or use [nvm](https://github.com/nvm-sh/nvm).

## Content

Edit files in `src/content/`:

- `profile.ts` — name, tagline, about, social links
- `experience.ts` — work history
- `projects.ts` — featured and archive projects

## Deploy

Push to GitHub and deploy on [Vercel](https://vercel.com). Point the `yashab.com` domain to this repository.
